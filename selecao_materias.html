QuadriSync: Otimizador Logístico de Grades

Contexto: Automação e Resolução de Dependências Acadêmicas (UFABC).

Ferramentas: Python 3 (Pandas, pdfplumber, PyMuPDF) e Excel (openpyxl).

Ver Código no GitHub

1. Motivação e Descrição do Projeto

O QuadriSync é uma ferramenta de automação desenvolvida para resolver um dos problemas logísticos mais complexos do ambiente universitário da UFABC: a montagem de grades horárias eficientes. Devido à mecânica diferenciada de quadrimestres e pré-requisitos, o processo manual é custoso e passível de erros.

Cruzando o histórico escolar do aluno, o projeto pedagógico institucional e o catálogo de turmas ofertadas no período, o motor gera uma grade de disciplinas otimizada, livre de choques de horários e estritamente alinhada com as metas estratégicas de formatura do aluno.

2. Como o Algoritmo Funciona

A arquitetura do sistema foi desenhada para atuar como um Resolver (Resolvedor de Dependências) e funciona através das seguintes etapas lógicas:

  • Extração de Dados Híbrida (ETL): Realiza o parsing do histórico escolar em PDF utilizando pdfplumber e fitz, contando com um sistema de fallback automático para tratamento de exceções (como PDFs gerados sem linhas de grade visíveis).
  • Mapeamento de Pendências: Identifica as disciplinas obrigatórias e limitadas restantes, isolando e saneando os dados de forma automatizada.
  • Classificação Hierárquica Absoluta: Ordena a fila de prioridades através de uma política rigorosa de pesos para acelerar a transição entre ciclos acadêmicos (forçando a finalização do Bacharelado Interdisciplinar antes de alocar disciplinas do Ciclo Profissional).
  • Motor de Alocação: Varre as ofertas de turmas tentando preencher os slots de tempo, validando choques de horários na matriz semanal, alternância de turmas quinzenais, e respeitando um teto rigoroso de limite de créditos.
  • Exportação e Resumo Visual: Emite um relatório analítico no console e gera uma planilha interativa formatada condicionalmente em .xlsx.

Tecnologias Empregadas

Python 3 & Pandas: Linguagem base da arquitetura lógica, utilizada para manipulação de DataFrames, cruzamento de dados e processamento matemático das matrizes horárias.
pdfplumber / PyMuPDF: Engenharia de extração estruturada de informações em documentos PDF.
openpyxl: Módulo de integração para conversão de matrizes lógicas em planilhas Excel formatadas para o usuário final.
